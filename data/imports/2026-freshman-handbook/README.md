# 2026 新生手册导入说明

- 输入文件由维护者在本地执行导入命令时显式提供，不存入仓库或 `public/`。
- 标题：仰恩大学新生手册 2026
- 署名：阿杰
- 性质：学生整理资料，不是学校官方通知
- 导入：`pnpm exec tsx scripts/import-freshman-handbook.ts <本地PDF路径>`

导入会保存完整 PDF 正文、按页建立学生经验检索条目，并把自动切分的知识声明放入审核队列。报到地点、票价、快递站点、缴费和军训安排等易变化内容不能覆盖学校官网原文或已审核站内资料。

导入只保留用于站内检索的结构化文字，不公开分发原 PDF 或其中的照片。
