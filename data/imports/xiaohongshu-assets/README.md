# 小红书图片核验素材

本目录保存项目维护者要求获取的少量公开笔记图片，仅用于资料核验和后续现场采集规划。

- 未取得原作者或权利人的转载授权，全部标记为 `research-only`。
- 文件不放入 `public/`，前台、PWA 和后台预览都不得默认加载。
- 稳定来源链接、作者页面显示名称、获取日期、尺寸、哈希和风险说明见 `manifest.json`。
- 宿舍图片不能代表所有楼栋、性别或房型；快递地图可能过期；菜品与店铺归属仍需现场核验。
- 叮叮车笔记中的多张车辆图存在明显生成或合成风险，禁止作为真实校园照片使用。

取得明确授权后，应在清单中补充授权人、授权范围、授权日期和证据引用，再将经审核的副本移入正式媒体库。
