## 1. 一句话定位

**仰恩新生「可搜索、可定位、可办事」的一站工具，不是又一篇经验合集。**

普通小红书帖解决的是「别人怎么说」；我们解决的是「打开就能照着做」。

| 维度 | 普通新生帖 | 仰恩新生指南 |
| --- | --- | --- |
| 形态 | 图文/视频经验 | 可点可用的 Web 工具 |
| 找路 | 只写楼名 | 地图标点 + 官方平面图热点 + 外跳导航 |
| 办事 | 步骤不全、易过期 | 报到 / 校园卡 / 网络等结构化流程 |
| 信息可信 | 来源不清 | 来源与核验可追溯 |
| 使用门槛 | 收藏后还得再搜 | 免登录，手机 / 微信直接打开 |
| 时效 | 一次性帖 | 持续更新；后续接 Agent 搜索 |

## 2. 目标用户与场景

| 人群 | 核心焦虑 | 内容切入 |
| --- | --- | --- |
| 本科新生 | 第一次来，怕迷路、怕漏办 | 地图 + 报到流程 |
| 专升本新生 | 流程是否不同 | 「专升本也能用」专场 |
| 陪同家长 | 校门、报到点、落客 | 首页 + 地图截图 |
| 已录取未到校 | 提前囤信息 | 工具帖 + 生活服务预览 |

**核心 KPI（优先于粉丝数）**

1. 小红书 → 站点点击（链接 / 主页备注）
2. 地图页 / 平面图打开与停留
3. 报到流程页打开
4. 反馈纠错提交（质量信号）

---

## 3. 差异化卖点（发帖必带 3 选 2）

1. **地图优先**：宿舍、教学楼、快递点不是空名字，能点、能定位、能外跳导航。  
2. **官方平面图 + 编号热点**：拖动查看，点击标点不乱跳（保持当前缩放）。  
3. **报到可照做**：步骤、材料、地点串起来。  
4. **市面攻略高频主题全覆盖**：宿舍 / 报到 / 校园卡 / 网络 / 快递外卖 / 周边 / 社团。  
5. **免登录免费**：微信内也能打开。  
6. **后续 Agent 搜索**：从「自己翻」升级为「直接问」。

**合规句（每帖末尾固定）**

> 本站为非学校官方平台，由学生团队维护；报到时间、收费、政策等以学校正式通知为准。

## 6. 发帖操作清单

1. **账号**：个人 / 学生向真实感更好；简介写「仰恩新生工具整理 · 非官方」+ 链接（若平台允许）。  
2. **主页备注 / 评论置顶**：固定放 `https://yeu.huiliyill.cn`。  
3. **图片顺序建议（工具帖）**  
   1. `01-cover.png` 封面海报  
   2. `page-home.png` 真实首页  
   3. `page-map.png` 地图  
   4. `page-procedures.png` 办事  
   5. `02-compare.png` 或 `03-features.png`  
4. **文案**：前 3 行必须有钩子（别翻群聊 / 第一次来仰恩 / 一张图搞定）。  
5. **评论区预埋**：自己第一条评论放链接 + 「非官方」。  
6. **禁止**：冒充学校官方、承诺绝对准确、搬运他人未授权实拍当本站素材。  
7. **数据**：每周看点击与地图/报到页打开，下周只加码高转化主题。

## 10. 风险与红线

1. **不冒充官方**，每帖标明非官方。  
2. **不承诺绝对准确**；日期收费以通知为准。  
3. **不使用未授权他人实拍 / 疑似生成却伪装实拍**的素材（见 `docs/XIAOHONGSHU_RESEARCH_2026-07-15.md`）。  
4. **不在营销文档或帖子中暴露密钥、后台、CDN Token**。  
5. 评论区遇质疑：引导反馈纠错 + 标明信息来源策略，不争论「是不是官方」。
