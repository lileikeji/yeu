## 1. 审计结论

本轮发现三组“已经公开，但授权记录不足”的媒体：小红书研究素材衍生图、学校官网校园平面图完整副本、旧学校官方 Logo 副本。三组旧素材曾从公开目录和公开展示中撤下；事实研究记录、来源 URL、哈希和必要的内部母版按最小化原则保留。维护者随后明确提供根目录 `logo.png` 并要求用于首页，并于 2026-07-16 要求恢复经过字节核验的官网校园平面图及热点。两项操作记录证明素材来源和维护者意图，但不等同于权利人授权。

当前 `public/` 中保留 PWA 图标、favicon、维护者指定的站点 Logo、已优化首页校园背景，以及维护者要求恢复的官网校园平面图快照。后续新增公开媒体必须记录作者/权利人、许可范围、许可证据、审核人、审核日期和撤回方式；站点 Logo 与校园平面图在正式公开前仍需补齐同等记录。

## 3. 自动化发布约束

`scripts/public-media-policy.test.ts` 固定以下规则：

- 小红书视觉重构目录不得出现在 public。
- 官网校园平面图快照是显式大图例外，必须与登记的 `1,250,742` 字节和 SHA-256 完全一致，并且只能由平面图视图按需加载。
- 已撤下的 `public/images/yeu-logo.svg` 或其他未登记学校 Logo 副本不得重新进入 public。
- 当前 `/icons/site-logo.png` 必须与维护者提供的根目录 `logo.png` 字节一致，尺寸为 `325×72`，且默认布局不能声称它是“仰恩大学校标”或暗示官方背书。
- 自动化门禁只验证文件来源、尺寸和界面表述；Logo 与校园平面图授权证明仍由发布前人工审查负责。

`scripts/xiaohongshu-images.test.ts` 进一步验证研究文件索引完整、公开副本不存在、原始素材清单仍保持 `research-only`。原始 WebP 与重构 PNG 均由 `.gitignore` 排除，避免在公开 Git 仓库中形成新的未授权分发。
