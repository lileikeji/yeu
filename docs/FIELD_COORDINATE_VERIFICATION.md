# 现场坐标采集与审核

## 1. 目标

现场采点用于把“缺少坐标”的地点草稿逐步转成可审计的 WGS84 主导航点。采点记录与地点发布状态分离：采集成功只生成待审核观测，不会自动发布地点，也不会自动刷新地点内容的 `last_verified_at`。

入口：`/admin/field-observations`。生产环境必须使用 HTTPS；`localhost` 仅用于本机开发。浏览器定位权限由操作人主动授予，系统不后台持续定位。

## 2. 采集规则

- 选择正式地点记录，不在现场临时创建同名地点。
- 选择“主入口”或“场地点”；教学楼、宿舍和行政服务优先采主入口，而不是建筑几何中心。
- 浏览器现场采点只收录设备报告精度为 25 米或更好的修复，每次采集 5 至 7 个样本，相邻样本至少间隔 3 秒且总时长至少 12 秒；服务端仍最多接受 10 个样本，以兼容授权导入和历史记录。
- 每个样本保存 WGS84 经度、纬度、设备报告精度和采集时间。
- 服务端计算经纬度中位点，并取“设备报告精度中位数”和“样本最大离散距离”中的较大值作为有效精度。
- 现场页面使用同一口径实时显示聚合点、最大离散、采样时长和有效精度；未达到 25 米有效精度或时长不足时不能提交，必须到更开阔的位置重采。
- 必须填写现场证据说明，例如正式标牌、入口方向和可辨认参照物；不得记录同行学生、宿舍房间或个人行程。
- 请求失败时可暂存在浏览器 IndexedDB；本地队列只在当前设备保存，恢复网络后由管理员主动同步。

## 3. 审核规则

- 观测初始状态为 `pending`，不会修改地点坐标。
- 普通地点编辑表单不能写入 `verified`，也不能填写坐标核验时间。
- 批准前必须填写审核记录；设备有效精度必须为 25 米或更好。
- 校内地点超出 OSM 候选校界的审核缓冲范围时禁止批准。该范围只用于异常拦截，不是官方权属边界。
- 第一条观测批准后写为 `approved`，地点保存该 WGS84 候选点和 `coordinate_point_role`，但坐标状态最多只能是 `unverified`，`coordinate_verified_at` 保持为空。
- 只有第二条有效证据同时满足以下条件，地点才升级为 `verified`：点位角色相同；两个聚合点相距不超过 20 米；至少一条来自 `browser-geolocation` 或 `authorized-import`；同一采集方式的两条记录至少相隔 30 分钟。不同数据库 ID 但来自同一采样会话的重复提交不算独立证据。
- `map-review` 可作为人工比对补充，但两条均为 `map-review` 不能完成双重核验。授权导入也只生成待审核观测，不能直接修改地点为 `verified`。
- 已核验地点始终保留两条有效 `approved` 证据。批准第三条兼容证据时，系统保留与新证据距离最近、精度更好且较新的一个旧证据；被替代记录改为 `superseded`，原审核人、审核时间和审核说明不被覆盖，并通过 `superseded_by_observation_id` 指向新记录。
- 新批准观测若与现有证据的角色、距离、可信采集方式或时间独立性不符，会成为新的首条候选；系统仍保留一条最相关的旧 `approved` 证据，多余冲突记录转为历史，地点降回 `unverified`，等待再次独立复核。
- 任何坐标值或坐标系发生变化时，旧 `external_map_url` 自动清空，避免外部导航继续指向旧点；点位角色随当前候选一并持久化。
- 驳回观测不会改变地点。精度不足的观测可保留为线索，但不得通过手工修改状态绕过。
- 地点发布仍需有效 A/B/C 来源和地点事实核验时间；坐标观测不能替代名称、用途、开放时间等事实来源。

从 `0005` 迁移开始，旧版本中由单次批准产生的 `verified` 坐标会降为 `unverified`，并从最近的有效批准记录回填点位角色。历史审核记录仍保留，后续须按上述双证据规则重新完成核验。

## 4. 首批顺序

1. 对外开放校门与主要入口。
2. 2026 级实际报到点，必须等当年通知后建立。
3. 主要教学楼、行政服务、图书馆、医务室。
4. 宿舍片区公共入口，不采学生房间或门禁细节。
5. 食堂、体育场馆、快递点和取餐点；运营规则仍需单独来源。

每个 P0 点必须有第二条独立观测才能成为 `verified`。现阶段单管理员模式允许同一账号审核，但同一账号不改变采集独立性要求，审核记录仍必须说明比对依据。

## 5. 数据与隐私

`place_coordinate_observations` 保存聚合坐标、原始样本、采集方式、点位角色、有效精度、现场说明和审核链。公开 API 不返回待审核观测；只有地点通过发布门槛后，前台才获得导航坐标。

离线队列不得用于记录人员定位。完成同步后会从 IndexedDB 删除；共用设备离场前应确认队列为空并退出后台。
