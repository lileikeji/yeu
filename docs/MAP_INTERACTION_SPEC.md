# 地图交互规范

> 文档版本：0.1
> 适用范围：公开端 `/map`、地点选择器与地图降级页面
> 目标设备：桌面浏览器、手机浏览器、微信内置浏览器、已安装 PWA
> 关联文档：[PRD.md](./PRD.md)、[INFORMATION_ARCHITECTURE.md](./INFORMATION_ARCHITECTURE.md)、[ARCHITECTURE.md](./ARCHITECTURE.md)

## 1. 目的与参考边界

本规范定义仰恩新生指南地图的原创交互方案。它参考了已验证的高德“地图工作台”在列表与地图联动、标点标签和选中详情方面的空间关系，但不是对该产品的视觉复刻。

### 1.1 已观察到的参考行为

- 桌面端以约 280px 左侧地点列表配合右侧地图。
- 常态点位使用蓝色水滴形标点，带白色描边/中心，名称紧邻标点显示。
- 少量线与面分别使用橙色、绿色等强调色。
- 点击列表项后，地图平移到目标地点，在标点附近显示白色详情卡；列表保留并高亮当前项。
- 详情卡包含名称、地址、维护者/更新时间、简介，以及编辑、记录、打卡、删除、详情等工作台操作。
- 全览时宿舍、教学楼等密集标签重叠严重。
- 缩小到市级仍没有数字聚合，只有部分点因碰撞或覆盖可见。

这些事实只用于理解交互问题。项目不复制参考产品的图标素材、品牌色、标点造型细节、卡片排版、文案、操作集合或源代码。

### 1.2 本项目采用与改进的部分

| 参考点 | 本项目决定 |
| --- | --- |
| 左侧列表 + 右侧地图 | 桌面保留约 280px 列表；移动端改为底部抽屉 |
| 彩色图钉 + 名称标签 | 使用项目自有颜色、原创容器和 Lucide 图标；名称按缩放级别出现 |
| 列表点击定位 | 保留列表/标点双向选中、平移、列表高亮和状态恢复 |
| 标点旁详情卡 | 桌面使用锚定浮层；移动端使用底部抽屉，避免遮挡地图 |
| 密集标签全部出现 | 改为标签碰撞隐藏和优先级排序，不允许不可读重叠 |
| 低缩放无数字聚合 | 改为低缩放数字聚合，点击聚合点后缩放至包含范围 |
| 工作台编辑/删除等操作 | 公开端不采用；替换为详情、导航、分享和纠错 |

### 1.3 原创性要求

- 标点颜色来自本项目设计令牌，不使用高德蓝或其他产品品牌色作为默认复刻色。
- 图标优先使用项目已启用的 Lucide 图标，不下载、描摹或重新打包高德专有图标。
- 水滴/图钉外形使用通用几何或 Lucide `MapPin` 语义，不复刻专有比例、阴影和中心图案。
- 卡片、列表行、聚合点和线面样式均按本项目设计系统实现。
- 不从参考页面复制 DOM、CSS、截图切图、文案或交互代码。
- 地图底图、Logo、署名和数据的使用必须遵守所选地图服务条款。

## 2. 体验目标

地图交互按以下优先级设计：

1. 用户快速确认“目标在哪里、是否是我要找的地点”。
2. 密集点位下仍能看清选择，不用在重叠标签中猜测。
3. 列表、地图、详情三种表达共享同一个选中状态。
4. 地图或定位能力失败时，地点文本和导航信息仍可使用。
5. 桌面充分利用宽度，手机保持单手操作和足够地图可视区域。
6. 不依赖悬停、特定浏览器 API 或账号完成核心任务。

## 3. 响应式布局

### 3.1 布局断点

断点以可用内容宽度为准，不能只按设备名称判断。

| 可用宽度 | 地点结果 | 地图详情 | 主要行为 |
| --- | --- | --- | --- |
| `>= 1024px` | 左侧固定约 280px，可在 272-304px 内响应 | 标点附近白色浮层 | 始终并列，列表不因打开详情消失 |
| `768-1023px` | 左侧 304px 可折叠面板或列表/地图分段视图 | 优先侧栏详情，空间不足时底部抽屉 | 保证地图主区域不窄于可操作宽度 |
| `< 768px` | 地图上的底部抽屉承载结果列表 | 同一抽屉切换到地点摘要/详情 | 地图近全屏，使用安全区和三档停靠高度 |

如果嵌入容器宽度与视口不一致，组件以容器查询或实际可用宽度选择布局。

### 3.2 桌面布局

```text
+--------------------------+------------------------------------------+
| 地点列表，约 280px       | 地图                                     |
| 搜索/筛选摘要            | 搜索与分类工具条                         |
|                          |                                          |
| > 当前选中地点           |       [选中图钉]--[地点详情浮层]         |
|   其他地点               |                                          |
|   其他地点               |                         定位 / 全览     |
+--------------------------+------------------------------------------+
```

- 列表是地图工作区的一部分，不做装饰性悬浮卡片。
- 列表宽度默认 280px；用户缩放文字到 200% 时允许增宽或切换中等布局，不截断关键操作。
- 搜索与主要筛选放在列表顶部或地图顶部稳定区域，滚动列表时仍可访问。
- 地图填充剩余空间，工具控件与地图服务署名不重叠。
- 详情浮层锚定选中标点，默认宽 300-336px；应自动换边、向上/向下偏移或轻微平移地图，不能越出可视区域。
- 打开浮层后左侧列表仍可滚动，当前项持续高亮并保持可见。

### 3.3 移动布局

```text
+--------------------------------------+
| 返回  搜索地点              筛选     |
|                                      |
|                地图                  |
|                                      |
|                         定位 / 全览  |
|--------------------------------------|
| ─  底部抽屉：列表或选中地点摘要      |
|    可上拉展开、下拉收起               |
+--------------------------------------+
```

- 地图占据扣除站点导航后的可用高度，底部抽屉覆盖其下部但保留足够浏览区域。
- 抽屉包含三个停靠状态：收起约 96px、半屏约 45% 可用高度、展开不超过 85% 可用高度。
- 停靠尺寸需考虑 `env(safe-area-inset-bottom)`，不被 iPhone Home Indicator 或 PWA 窗口边缘遮挡。
- 点击标点时抽屉显示地点摘要并至少进入半屏；点击摘要的“查看详情”进入完整地点页或抽屉展开态。
- 点击搜索结果时，先定位并选中地点，再进入摘要态；不立即跳离地图。
- 用户开始拖动地图时可将展开抽屉收至半屏，但不能清除选中状态。
- 抽屉拖拽手柄具有可访问名称；不支持拖拽的用户可用“展开/收起”按钮完成同一操作。
- 地图控件根据当前抽屉高度上移，任何停靠状态都不得被抽屉遮挡。

### 3.4 横屏与小高度

- 手机横屏或可用高度低于 480px 时，不强制三档抽屉；使用列表/地图分段控件或窄侧栏。
- 搜索、返回和关闭等主操作始终可见，不因地图高度不足互相覆盖。
- 虚拟键盘打开时冻结不必要的地图尺寸动画，并保证搜索结果可见。

## 4. 地图视觉语法

### 4.1 项目自有颜色

颜色按语义类别配置为设计令牌，而不是散落在组件中。以下为建议起点，最终需在真实底图上做对比度检查：

| 类别 | 建议色 | 语义示例 |
| --- | --- | --- |
| 教学/学习 | `#2563EB` | 教学楼、图书馆、实验楼 |
| 宿舍/生活 | `#0F766E` | 宿舍、公共生活设施 |
| 餐饮 | `#B45309` | 食堂、校内餐饮 |
| 行政/服务 | `#7C3AED` | 报到点、部门、校园卡/网络窗口 |
| 医疗/安全 | `#DC2626` | 医务、安全和紧急服务 |
| 快递/交通 | `#475569` | 快递、校门、公交/落客点 |
| 周边商铺 | `#C2410C` | 校外餐饮、零售和生活服务 |
| 其他 | `#4B5563` | 尚未归类地点 |

- 同一界面不能只靠颜色区别类别；标点内使用对应 Lucide 图标或文字类别，列表同步显示类别名称。
- 状态色与类别色分离：待核实、停用、推广等状态使用文字/徽标和线型表达，不覆盖地点类别含义。
- 线和面使用各自令牌，例如步行参考线、校园边界、运动区域；不沿用参考产品的橙/绿组合。
- 面填充保持低透明度，边界有清晰描边，不遮住底图道路与建筑名称。
- 地图服务本身的品牌、道路和 POI 样式不纳入项目视觉令牌。

### 4.2 常态图钉

- 视觉尺寸固定为 `32 x 32px`，点击/触控命中区域至少 `44 x 44px`。
- 使用项目类别色填充，白色内描边或白色中心图标，保证在深浅底图上可辨认。
- 内部图标优先使用 14-16px Lucide 图标，如 `Building2`、`GraduationCap`、`House`、`Utensils`、`HeartPulse`、`Package`、`BusFront`、`Store`。
- 图钉尖端对准地理坐标；命中区域可向四周扩展，不能改变锚点。
- 常态轻阴影只用于与底图区分，不制造悬浮装饰感。
- 不允许因为名称变长改变图钉尺寸或锚点。

### 4.3 选中图钉

- 视觉尺寸固定为 `44 x 44px`，保持原坐标锚点，使用短动画从常态过渡。
- 采用白色双描边或白色外环 + 内描边，并增加轻阴影；颜色仍保持原类别色。
- `z-index` 高于所有常态点、标签和聚合点，选中点不得被碰撞隐藏。
- 选中名称标签始终显示，必要时隐藏邻近低优先级标签。
- 动画时长建议 150-200ms；用户启用 `prefers-reduced-motion` 时取消缩放/弹跳，仅切换描边和层级。
- 同一时刻只有一个地点处于主选中态；聚合点是临时聚焦，不占用地点选中态。

### 4.4 名称标签

- 名称紧邻图钉，默认位于右侧或上方，保持 4-6px 间距。
- 使用 12-13px 清晰字重、0 字距，浅色文字描边或实色小底板由底图对比度测试决定。
- 标签不可捕获指针事件；点击目标是图钉或列表项，避免文字遮挡相邻点命中区域。
- 最长展示建议 12 个中文字符；更长名称使用语义完整的短名称，完整名称保留在列表和详情。
- 标签碰撞时隐藏整个低优先级标签，不允许文字互相覆盖、半截裁切或挤压变形。
- 标签隐藏只影响视觉，不从搜索、列表和无障碍树中删除地点。

### 4.5 聚合点

聚合点显示当前聚合内的地点数量，按数量使用稳定尺寸：

| 数量 | 视觉尺寸 | 内容 |
| --- | --- | --- |
| 2-9 | 36px | 完整数字 |
| 10-49 | 44px | 完整数字 |
| 50 及以上 | 52px | 最高显示 `99+`，可访问名称读出真实数量 |

- 聚合使用项目中性/品牌辅助色与白色双描边，不能伪装成普通地点。
- 点击或按 Enter 激活聚合点后缩放至其成员边界；如果已到最大缩放仍重叠，展开可选择的地点列表，而不是无限放大。
- 聚合点的触控目标不得小于视觉尺寸和 44px 两者中的较大值。
- 聚合数量只统计当前搜索和分类筛选后的已发布地点。
- 聚合动画遵循减少动态效果设置。

## 5. 缩放、碰撞与密度策略

地图供应商的缩放定义可能存在差异，以下阈值作为初始配置，必须通过校园真实点位调校并集中配置。

| 参考 zoom | 显示策略 | 标签策略 |
| --- | --- | --- |
| `< 13` | 以数字聚合为主，仅保留校园中心/校门等极少锚点 | 仅锚点标签 |
| `13-14.99` | 聚合为主，高优先级独立地点可出现 | 选中点、搜索命中和校园锚点 |
| `15-16.99` | 展开多数点；局部密集区仍聚合 | 选中点、任务相关点和高优先级点 |
| `>= 17` | 展开独立地点；完全重合点进入同址选择 | 在碰撞检测允许时显示名称 |

### 5.1 标签优先级

碰撞时从高到低保留：

1. 当前选中地点。
2. 精确搜索命中地点。
3. 当前报到流程或指南关联地点。
4. 用户主动筛选后剩余的高频地点。
5. 校门、报到点、医疗等关键地点。
6. 编辑精选地点。
7. 其他普通地点。

同一优先级按与视图中心距离、稳定 ID 排序，避免轻微拖动导致标签持续闪烁。

### 5.2 碰撞规则

- 碰撞框包含图钉、标签及必要间距；选中点不参与被隐藏计算，但会压低周边标签优先级。
- 普通标签可隐藏，普通图钉只有在聚合或完全重合处理时隐藏。
- 密集宿舍/教学楼区域优先保留不同类别和关键入口，而非只保留数据顺序靠前的点。
- 缩放、筛选或选中改变时重新布局；普通平移期间保持布局稳定，在 `moveend` 后更新。
- 低 zoom 不依赖随机覆盖制造“看起来较少”的效果，必须通过可解释的数字聚合表达数量。

### 5.3 同址与近距地点

- 同一建筑内的楼层、窗口或房间可共享建筑坐标，但地图默认先显示建筑主点。
- 选择建筑后在详情卡/抽屉中展示内部地点，不把多个图钉无限错位散开。
- 确有多个独立入口时允许保留近距点，并通过入口名称和照片区分。
- 最大 zoom 下仍无法分别命中的地点，点击后显示同址地点选择列表。

## 6. 列表、地图与详情双向联动

### 6.1 单一状态模型

公开地图至少维护以下可恢复状态：

- `query`：搜索词。
- `categories`：分类筛选。
- `scope`：校内/周边。
- `selectedPlaceId`：当前选中地点。
- `viewport`：中心、zoom 和可视边界。
- `resultMode`：全部筛选结果或用户主动确认的当前区域结果。
- `drawerSnap`：移动抽屉停靠状态，只在当前会话保存。

URL 只同步适合分享的 `q`、`category`、`scope` 和 `place`；瞬时视口和抽屉状态默认不写入 URL。

### 6.2 点击列表项

1. 设置唯一 `selectedPlaceId`。
2. 列表项进入高亮态，并滚动至完整可见；用户刚主动滚动列表时不强制抢夺滚动。
3. 地图平移至目标坐标；当前 zoom 足够时不重置，目标不在视口或过远时提升到地点可读 zoom。
4. 图钉切换为 44px 选中态并提高层级。
5. 桌面在标点附近打开详情浮层；移动端抽屉进入地点摘要。
6. URL 更新 `place`，保留当前搜索和筛选参数。

### 6.3 点击标点

1. 设置唯一 `selectedPlaceId`。
2. 左侧列表或移动结果列表定位并高亮对应项。
3. 必要时轻微平移地图，为详情浮层/抽屉和地图控件留出安全区域。
4. 打开对应详情，不改变用户已有搜索和筛选。
5. 向辅助技术播报地点名称、类别和区域。

### 6.4 点击聚合点

- 不选择其中任一地点。
- 地图缩放至聚合成员的包含边界，并保持筛选。
- 到最大 zoom 后显示成员列表，由用户明确选择地点。
- 返回操作恢复聚合前视图仅作为会话内增强，不要求写入分享 URL。

### 6.5 关闭详情

- 关闭浮层/摘要后取消主选中态并移除 URL 中的 `place`，但保留搜索、筛选和当前视口。
- 从独立地点详情返回 `/map` 时恢复之前的搜索、筛选、视口和选中项；从外部深链接进入时使用校园合理默认视图。
- `Escape` 先关闭详情，再关闭筛选面板，最后才由浏览器处理返回。

### 6.6 地图拖动与“搜索此区域”

- 普通拖动地图不立即改变结果列表，避免列表在拖动过程中跳动。
- 地图离开当前结果范围后显示“搜索此区域”按钮；只有用户主动点击才以可视边界更新列表。
- 切换分类/关键词后重新以全部匹配结果计算全览，不暗中继承旧的区域约束。
- 当前选中地点被新筛选排除时，清除选中与详情并给出简短状态提示。

## 7. 搜索、筛选与地图工具

### 7.1 搜索

- 搜索覆盖名称、别名、类别、用途和常用问法。
- 输入后 200-300ms 防抖；中文输入法组合输入期间不提交查询。
- 精确命中一个地点时可自动选中，但不能在用户仍输入时反复平移地图。
- 多结果按相关性显示列表，地图只显示当前结果集合。
- 无结果保留搜索词，提供清除筛选、浏览类别和反馈缺失地点。

### 7.2 分类筛选

- 桌面在列表顶部显示分类菜单/筛选面板；移动端使用横向快捷项和完整筛选抽屉。
- 支持校内/周边范围切换及宿舍、教学楼、行政服务、餐饮、医疗、快递、外卖、交通、商铺等分类。
- 已选条件以可移除项显示，提供“清除全部”。
- 筛选会更新列表、图钉、聚合数量和全览边界，四者结果必须一致。

### 7.3 全览

- 使用 Lucide `Maximize2` 或适合语义的图标按钮，并提供“全览”工具提示/可访问名称。
- 有搜索/筛选结果时适配当前结果边界；无结果时恢复预设校园边界。
- 只有一个结果时使用地点可读 zoom，不放大到建筑纹理失去上下文。
- 全览不清除搜索、筛选或选中地点；选中地点保持可见。

### 7.4 定位

- 使用 Lucide `LocateFixed`，首次请求前说明“仅用于在地图上显示你的位置”。
- 用户位置使用独立样式，不复用地点图钉和类别颜色。
- 成功后将位置移入安全可视区域，不自动开启持续追踪。
- 拒绝、超时、不安全上下文或微信 WebView 失败时说明原因和替代操作，不循环弹出授权。
- 精确位置默认不发送到业务服务器，也不写入访问日志或分享 URL。

### 7.5 导航

- 导航入口只在明确选中地点后可用。“地图内路线”使用 Lucide `Route`，外部入口使用 Lucide `Navigation` 和“高德导航”文字。
- 高德地图模式优先获取一次当前位置并在当前地图绘制步行路线，显示距离、预计时间和清除入口；不持续追踪，也不把位置发送到本站业务服务器。
- 保留高德 URI 外部导航作为手机、PWA 和微信内访问的兜底，明确使用 GCJ-02 目的坐标。
- 微信内无法唤起时提供“复制地址”“复制坐标/地点链接”和“在浏览器打开”。
- 地址为空时使用已核验地点名称和坐标，不拼接未经核实的文字地址。

### 7.6 其他控件

- 列表/地图切换使用分段控件和 Lucide `List`、`Map`。
- 桌面端地点侧栏支持收起与恢复，收起后地图占满可用宽度；移动端继续使用半屏抽屉高度控制。
- 图层设置支持标准地图/卫星地图切换，以及标记点、真实区域边界、名称、自动聚合和四档名称字号即时切换。
- 行政分块只有在取得学校或供应商可信边界数据后才能启用；无数据时控件保持禁用并说明原因。
- 关闭详情使用 `X` 图标并提供可访问名称；展开/收起使用 `ChevronUp`/`ChevronDown`。
- 不熟悉的纯图标按钮必须有悬停工具提示；触屏不能依赖工具提示才能理解核心动作。
- 地图服务提供的缩放、指南针和署名按许可保留，项目控件不覆盖它们。
- 校园区域只绘制不规则边界线，不添加覆盖整个区域的可点击填充面；标签禁用指针事件，确保区域内部的高德原生商铺仍可点击。
- 点击区域边界显示名称、面积、周长、来源与说明；面积和周长直接来自 WIA 资源详情，不由前端根据屏幕像素估算。

## 8. 地点摘要与详情

### 8.1 桌面浮层

浮层包含：

1. 地点名称、类别、区域和核验/状态标签。
2. 简短地址或“区域 + 楼栋 + 楼层/房间”。
3. 1-3 行摘要。
4. 最后核验日期；不公开后台管理员个人身份。
5. “查看详情”“导航”主要操作，以及分享、纠错次要操作。

不在公开浮层加入编辑、记录、打卡、删除等工作台操作。后台如复用地图选点，应使用独立管理组件和权限保护，不能让管理按钮进入公开端 DOM。

### 8.2 移动端摘要

- 收起态显示名称、类别/区域和展开按钮。
- 半屏态增加地址、摘要、最后核验日期及详情/导航操作。
- 完整长文、来源列表、图片和关联事项进入 `/places/:slug`，不把底部抽屉变成长文阅读器。
- 文本变长时抽屉内部滚动，地图和页面本身不能形成无法判断的双重滚动。

### 8.3 焦点与关闭

- 指针选择地点后不强制把键盘焦点移入浮层；键盘激活地点后，焦点进入浮层标题或首个操作。
- 关闭后焦点回到触发的列表项或标点；触发对象不再存在时回到搜索框或结果列表标题。
- 浮层不是阻断式模态框，用户仍可操作列表和地图；移动端全屏详情抽屉若形成模态状态则需正确设置焦点边界。

## 9. 键盘、触控与无障碍

### 9.1 键盘

- `Tab` 依次访问搜索、筛选、列表项、地图工具和详情操作，顺序与视觉布局一致。
- 列表项使用按钮或链接语义，`Enter`/`Space` 选中地点。
- 地图画布支持供应商已有的方向键、`+`/`-` 缩放时不得阻断浏览器快捷键。
- 不让数百标点全部进入 Tab 序列；列表是完整地点集合的主要键盘入口。地图内采用漫游焦点，只保留当前/最近点可聚焦。
- `Escape` 关闭当前浮层或抽屉展开态，行为可预测。
- 焦点样式不只依赖颜色，并在地图底图上保持明显。

### 9.2 触控

- 所有交互命中区域至少 44 x 44px；32px 常态图钉通过透明命中区满足要求。
- 不依赖悬停显示必要信息；第一次点击点位即完成选择。
- 双指缩放地图与单指拖动抽屉的区域明确分离；从抽屉内容区域开始的滚动不误拖地图。
- 地图控件之间至少留 8px，避免误触定位、全览和关闭。
- 长按不作为唯一操作，也不劫持浏览器/微信的系统菜单。

### 9.3 屏幕阅读器与文本替代

- 地图区域具备说明性名称，并提供“切换到地点列表”。
- 结果数、筛选变化、定位成功/失败和选中地点使用克制的 `aria-live` 状态播报。
- 图钉可访问名称包含“地点名称、类别、区域”；聚合点包含真实地点数量。
- 被碰撞隐藏的视觉标签不影响列表中的地点名称和详情可访问性。
- 线与面如承载校园边界或路线意义，提供文本说明；纯装饰图层从无障碍树隐藏。

## 10. 微信、PWA 与权限差异

### 10.1 微信内置浏览器

- 核心地图浏览、列表、筛选和详情不依赖微信 JS-SDK。
- 地理定位在 HTTPS、浏览器权限和系统权限任一失败时均走手动查找路径。
- 分享深链接打开后恢复 `place`、`q`、`category`、`scope`，不强制登录或跳首页。
- 外部导航被拦截时显示复制地址和浏览器打开选项，不持续自动跳转。
- 顶部/底部安全区域、微信工具栏和软键盘出现时重新计算可用高度，控件不相互覆盖。

### 10.2 PWA

- 独立显示模式下考虑状态栏和底部安全区，返回按钮行为与浏览器历史一致。
- Service Worker 只预缓存 `/offline.html` 及其必要 CSS、图标和字体，不预缓存 JavaScript；V1 的页面导航、公开内容 API、地图 SDK 与瓦片均不建立运行时内容缓存。
- 离线导航进入断网说明页，明确地图和地点正文当前不可取得，不展示未校验版本的缓存地点列表/详情。
- 恢复网络后由用户重试原页面；后续若引入已发布内容缓存，必须另行定义缓存时间、版本失效、强时效内容排除和恢复同步规则。
- PWA 安装提示不遮挡搜索、标点或底部抽屉。

## 11. 状态与降级

| 状态 | 地图区域 | 列表/抽屉 | 用户操作 |
| --- | --- | --- | --- |
| 初次加载 | 显示稳定占位，不展示随机假点 | 列表骨架与真实结果数占位 | 可返回；加载完成后保持布局不跳动 |
| 地点数据加载失败 | 底图可用时保留底图，无点位 | 明确错误原因的通用文案 | 重试、返回首页 |
| 地图 SDK/瓦片失败 | 用说明和校园文字概览替代画布 | 文本地点列表完整可用 | 搜索、筛选、详情、复制地址 |
| 空结果 | 保留当前视图，不伪造推荐点 | 显示搜索词/筛选导致无结果 | 清除条件、浏览分类、反馈 |
| 定位请求中 | 定位按钮显示进度，不锁住地图 | 列表照常使用 | 取消/继续浏览 |
| 定位拒绝/超时 | 不显示虚假用户位置 | 一次性说明，不反复弹窗 | 手动搜索、恢复校园全览 |
| 离线 | 不承诺保留底图，导航降级到断网说明页 | 不展示旧地点正文 | 重试连接、返回首页 |
| 选中内容下架 | 清除图钉或标为不可用 | 说明已下架，不保留旧导航按钮 | 搜索替代地点、返回分类 |
| 筛选后无点 | 保留校园背景和筛选状态 | 空状态 | 清除全部或逐项移除 |
| 外部导航失败 | 保持选中地点 | 摘要保留 | 复制地址/链接、重试 |

地图失败时列表不是次要提示，而是占据可用主区域的完整降级体验。地点文本必须在服务端或普通公开 API 中可用，不能依赖地图 SDK 初始化后才生成。

## 12. 性能与稳定性

- 地图首屏只请求视图与筛选所需的轻量地点字段，正文、图片和完整来源按需加载。
- 聚合和碰撞计算优先使用地图 SDK 原生图层或经过验证的空间索引，不逐点挂载重量级 Vue 组件。
- 搜索输入防抖 200-300ms；平移/缩放在 `moveend` 后更新碰撞与区域提示。
- 列表使用稳定 key；大量结果时使用分页或虚拟列表，但不能破坏键盘焦点和返回状态。
- 选中点更新、列表高亮和详情打开应在本地数据存在时即时完成，不等待二次网络请求才反馈。
- 地图加载与内容 SSR 分离，SDK 失败不影响页面标题、搜索入口和地点文本。
- 监控地图初始化失败、数据请求失败、聚合异常和外部导航失败，不采集连续精确位置轨迹。
- 以首批真实校园数据测试至少 300 个点位的平移、缩放、筛选和选中；未来超过阈值时再调整分块加载。

## 13. 推荐状态事件

以下事件名是产品语义，不绑定具体状态库：

| 事件 | 必要输入 | 结果 |
| --- | --- | --- |
| `place.select` | `placeId`, `source` | 同步列表、图钉、详情和 URL |
| `place.clear` | `reason` | 清除选中，保留查询/筛选/视口 |
| `cluster.expand` | cluster id/bounds | 缩放至成员边界或显示成员列表 |
| `filter.change` | categories/scope | 更新列表、点位、聚合和全览边界 |
| `search.submit` | query | 更新结果，不在组合输入阶段触发 |
| `viewport.commit` | bounds/zoom | 碰撞重算，显示“搜索此区域” |
| `viewport.fit` | result ids | 全览当前结果或校园默认边界 |
| `location.request` | user action | 请求一次定位权限 |
| `navigation.open` | place id/provider | 构造外部导航或进入降级路径 |
| `drawer.snap` | collapsed/half/expanded | 调整移动端控件安全区域 |

`source` 至少区分列表、标点、搜索、深链接、流程/指南关联，便于定位交互问题；匿名分析不得附带用户精确坐标。

## 14. 地图验收标准

### 14.1 布局与视觉

- 桌面宽度 `>= 1024px` 时显示约 280px 左侧列表与右侧地图，打开详情后列表不消失。
- 手机竖屏使用底部抽屉，收起、半屏、展开三态不遮住定位/全览控件和系统安全区。
- 常态图钉视觉尺寸为 32px、触控区至少 44px；选中图钉为 44px，具有白色双描边/外环、轻阴影和最高层级。
- 聚合点按 36/44/52px 三档显示数量，真实数量可被辅助技术读取。
- 使用项目自有颜色与 Lucide 图标，代码和资源中不包含参考产品专有图标或截图切图。

### 14.2 密度与缩放

- 在包含宿舍、教学楼等密集地点的校园全览中，不出现互相覆盖到不可读的名称标签。
- 低 zoom 使用数字聚合，不能依靠点位覆盖或随机隐藏来表达数量。
- 标签按 zoom 分级出现，并按规定优先级做碰撞隐藏；选中名称始终可见。
- 点击聚合点能缩放到成员边界；最大 zoom 仍重叠时可从成员列表选择。
- 缩放和平移后标签布局稳定，无明显闪烁或持续跳位。

### 14.3 双向联动

- 点击列表项后，地图平移到目标、图钉选中、桌面浮层/移动抽屉打开、列表项高亮，并保留搜索筛选。
- 点击图钉后，对应列表项滚动至可见并高亮；详情内容与图钉 ID 一致。
- 关闭详情只清除选中，不清除查询、筛选或视口。
- 从地点详情返回地图可恢复上一次选中与上下文；深链接在微信内打开可定位同一地点。
- 新筛选排除当前地点时，选中态和详情一起清除，不留下悬空卡片。

### 14.4 工具与降级

- 搜索、分类筛选、全览、定位和导航在目标浏览器可完成主路径。
- 拒绝定位后仍能搜索和选择地点，且不会反复请求权限。
- 微信无法唤起外部导航时能复制地址/链接或提示在浏览器打开。
- PWA 离线时进入预缓存的说明页，明确地图和最新地点内容不可用，并可重试或返回。
- 地图 SDK、瓦片或地点数据失败时展示相应错误状态；地图失败时完整文本列表可用。

### 14.5 键盘与触控

- 仅用键盘可完成搜索、筛选、从列表选点、打开详情、导航/复制地址和关闭详情。
- 选中变化、结果数和定位结果可被屏幕阅读器感知，不要求遍历所有地图标点。
- 200% 文本缩放、最长地点名、手机横屏和虚拟键盘状态下无控件/文字重叠。
- 所有触控操作不依赖悬停，命中区不小于 44 x 44px。
- 启用减少动态效果后，不出现必要信息依赖缩放或弹跳动画的情况。

## 15. 实施前待确认

- 生产地图供应商对自定义 HTML/图层标点、聚合、碰撞和 WebView 的实际支持方式。
- 真实校内地图常用 zoom 范围及不同设备像素密度下的阈值调校。
- 各类别最终设计令牌、Lucide 图标映射和线/面语义。
- 校园边界、分区、多入口和建筑内部地点的首批数据结构。
- 微信环境中的外部导航链接、系统浏览器提示及分享卡片能力。
- 后续内容缓存候选清单、版本失效规则，以及地图供应商对 SDK/瓦片缓存的许可边界。
