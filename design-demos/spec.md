# Design Spec · 仰恩大学迎新指南首页重构探索

## 1. 目标与媒介
- **输出形态**：响应式的网页高保真原型（三方向并行探索，选定方向后将重构落地至 `app/pages/index.vue`）。
- **对比尺寸**：桌面端 `1440×900`（首屏及完整长页）、移动端 `390×844`（手机竖屏逐屏验收）。
- **技术说明**：初稿为单文件 HTML（外链 Google Fonts 开源字体或系统兜底字体，图片使用相对路径或内嵌验证），保证导航、阶段 Tab、重要时间弹窗/展开、搜索交互真实可点且控制台零报错。

## 2. 受众与使用场景
- **场景 A（行前/桌面端）**：录取后查报到日期、看入学前准备事项、浏览校园真实风貌与宿舍/交通情况。
- **场景 B（到校当天/手机端）**：单手快速 AI 搜索、点开校园地图定位、拨打校园 110 / 教务 / 资助电话、核对准备清单进度。

## 3. 必须包含的真实核心信息模块（三版共用，严禁编造虚假内容）
1. **顶部全局导航与声明**：品牌「迎新指南｜学生整理 · 非官方」，主导航「首页 / 地图 / 办事 / 生活 / 热点 / 我的」，右侧「完整 / 简洁」视图切换提示与搜索/联系入口。
2. **重要时间提示条 & 详情面板**：「2026级新生重要时间」—— `9月5–6日 注册报到（看录取通知书）`、`9月7–9日 入学教育（看学院通知）`、`9月10日 开始上课（看教务系统）`。
3. **Hero 核心标题与 AI 搜索入口**：「2026级新生入学指南」，搜索框（`搜索校园信息，或输入你的问题`）+ `AI 搜索` 按钮。
4. **4 项高频常用查询**：
   - `报到安排`：查询报到时间、地点与流程（入学前先看）
   - `校园地图`：查找宿舍、教学楼和校园服务点（到校后常用）
   - `校园一卡通与网络`：查看校园网、校园卡和连接问题（入校后办理）
   - `快递与外卖`：查看取件站点、外卖送达和取餐说明（校园生活）
5. **最近在发（校内公告热度 + 校园活动）**：
   - 展示实时更新的公告条与近期活动结构（标注来源于公开通知整理，如报到接站与校巴班次、校园网统一认证开通、宿舍空调使用规定与报修流程等种子事项）。
6. **按入学阶段查看（3 阶段 Tab）+ 新生准备清单进度**：
   - `到校前`（确认报到时间与材料 / 查专业对应住宿片区 / 收藏校园地图认方向）
   - `报到当天`（按现场指引完成报到 / 到宿舍确认入住 / 核对一卡通和网络）
   - `入学第一周`（确认课表和教学楼 / 办理一卡通和网络 / 保存安全和办事入口）
   - 联动或并列「新生准备清单」：展示已完成百分比（如演示初始状态 35%）、下一项待办提示与打开清单入口。
7. **校内求助与常用电话（4 个真实公开号码）**：
   - 拨打校园 110：`0595-22076110`（报修 / 求助）
   - 心理健康中心：`0595-22099033`（咨询 / 适应支持）
   - 教务部：`0595-22082006`（学籍 / 课表）
   - 学生资助中心：`0595-22099018`（贷款 / 助学金）
   - 附注：医务室 24 小时值班 · 地图搜「医务所」
8. **全站服务导航（10 项完整校园生活入口）**：
   - 新生清单、安全医疗与心理支持、学生手册与资助、学生社团、校内部门、吃喝玩乐、到校与离校交通、全景云游校园、宿舍实拍、WeLearn 学习工具。
9. **诚实声明与官方来源核验区（Trust Notice）**：
   - 「学生整理 · 非学校官网」·「重要事项，再到学校原文确认一次」· 附学校官网、招生官网、学生资助、看信息从哪来、反馈纠错入口。

## 4. 质量硬约束
- 网页正文 ≥14px（移动端重点正文推荐 ≥15–16px），标签/Meta ≥12px，正文对比度 ≥4.5:1。
- 所有可点击元素热区高度 ≥44px（移动端不挤作一团）。
- 剔除「AI 模板装饰」：不写无意义全大写英文 eyebrow 标签、不用 `A · B · C` 中点拼凑装饰、按钮末尾不加 `→`、不用非序列的 `01/02/03` 编号装饰、不用 emoji 当图标、不用左彩条圆角卡片。
