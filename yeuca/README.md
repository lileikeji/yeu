# 仰恩计算机协会官网

一个面向仰恩大学计算机协会的静态站点。零前端框架、零运行时依赖、构建产物可直接扔进 nginx。

## 这个仓库里有什么

```
docs/     四份文档：逆向结论、建站方案、开源选型、实现配方
site/     Astro 站点源码（可构建）
_recon/   四个参考站点的抓取存档 + GitHub 调研原始数据
```

## 为什么要做，做成什么样

出发点是逆向四个真实的计算机社团官网，看它们各自怎么实现、哪些做法值得借。结论和证据在 [`docs/01-四站逆向.md`](docs/01-四站逆向.md)，建站决策在 [`docs/02-建站方案.md`](docs/02-建站方案.md)。

一句话概括取捨：**结构学江西农大（静态优先、内容与代码分离），视觉换成本校的红，交互零件从 Manipal ACM 和坎特伯雷计算机协会取，特效一律不做。**

## 本地开发

```bash
cd site
pnpm install
pnpm dev      # http://localhost:4321
pnpm build    # 产出 dist/
```

Node 需要 22.23.4 以上（Astro 7 的 engines 要求）。`pnpm build` 会先跑 `scripts/guard-build-host.mjs` 检查本机核数与内存，低于 8 核 / 8G 直接抛错——这是为了拦住「在生产机上构建」这个事故，云端 CI 用 `ALLOW_LOW_SPEC_BUILD=1` 放行。

## 部署

生产机是 4 核 / 3.6G，同机跑着 50 多个站点，**禁止在上面构建**（单次 40 分钟起，中途会被 OOM 杀，同机站点一起变慢）。正确链路是「本机出制品、服务器只解包切换」：

```
本机    bash scripts/build-linux-artifact.sh    # 产出约 16M 制品
服务器  bash /data/yeuca-build/deploy-incoming.sh  # 校验 + 备份 + 冒烟 + 切软链
```

`current` 是指向 `releases/<sha>` 的软链，回滚就是把软链指回去。部署脚本用 flock 串行，同一时刻只允许一个部署在跑。
