# 三个可以直接落地的实现配方

全部从 jxauac.cn 的线上产物里读出来的（不是猜的），改成仰恩可用的版本。总 JS 体积可以压在 3 KB 以内，零框架、零依赖。

---

## 配方 A：`data-*` 属性筛选器（成员名录 / 活动 / 项目通用）

线上原文（`/members/` 页内联脚本，22 行，服务 87 条记录、3 个筛选维度、实时显示计数）：

```js
(() => {
  const form = document.getElementById('member-filters');
  const search = document.getElementById('member-search');
  const major = document.getElementById('member-major');
  const grade = document.getElementById('member-grade');
  const result = document.getElementById('member-result');
  const empty = document.getElementById('member-empty');
  const cards = Array.from(document.querySelectorAll('[data-new-member]'));
  if (!form || !search || !major || !grade || !result || !empty || cards.length === 0) return;

  const normalize = (v) => v.trim().toLocaleLowerCase('zh-CN');
  const applyFilters = () => {
    const query = normalize(search.value);
    let visible = 0;
    for (const card of cards) {
      const matchesQuery = !query || normalize(`${card.dataset.name || ''} ${card.dataset.class || ''}`).includes(query);
      const matchesMajor = !major.value || card.dataset.major === major.value;
      const matchesGrade = !grade.value || card.dataset.grade === grade.value;
      const matches = matchesQuery && matchesMajor && matchesGrade;
      card.hidden = !matches;
      if (matches) visible += 1;
    }
    result.textContent = `显示 ${visible} 位成员`;
    empty.hidden = visible > 0;
  };

  form.addEventListener('input', applyFilters);
  form.addEventListener('change', applyFilters);
  form.addEventListener('submit', (e) => { e.preventDefault(); applyFilters(); });
  form.addEventListener('reset', () => requestAnimationFrame(applyFilters));
})();
```

配套 HTML（每个条目一个 `data-*`）：

```html
<li data-new-member data-name="张三" data-class="计科2602" data-major="计科" data-grade="2026级">
  <span class="avatar">张</span><span class="name">张三</span><span class="cls">计科2602</span>
</li>
```

**要点**

- 维度全部靠 `data-*`，筛选逻辑不认识业务字段名（改字段只改 HTML）。
- 用 `card.hidden = true/false` 而不是 `display:none`——原生属性，CSS 不用参与，屏幕阅读器也认。
- 计数用 `result.textContent` 实时更新，用户知道筛掉了多少。
- `reset` 事件要 `requestAnimationFrame` 包一层，否则读到的是重置前的值。
- Astro 里把这 22 行放进 `<script is:inline>`，构建后原样输出，不加任何运行时。

同样的结构可以直接套到活动页（`data-kind` / `data-year`）和项目页（`data-stack` / `data-status`）。muj.acm.org 那 7 个活动分类标签、5 个项目分类标签，本质就是这个。

## 配方 B：终端打字机

线上原文（`/` 首页 `[data-term]` 容器，逐行 `data-type`）：

```html
<div class="term-body" data-term>
  <span class="ln" data-type><span class="p">➜ ~</span> <span class="t" data-text="whoami">whoami</span></span>
  <span class="ln" data-type><span class="r">计算机协会 · est. [EST_YEAR]</span></span>
  <span class="ln" data-type><span class="p">➜ ~</span> <span class="t" data-text="cat mission.txt">cat mission.txt</span></span>
  <span class="ln" data-type><span class="r">小而美，一起做有趣的事。</span></span>
  <span class="ln" data-type><span class="p">➜ ~</span> <span class="t" data-text="./join --you">./join --you</span></span>
  <span class="ln" data-type><span class="a">[ok]</span> <span class="r">零基础欢迎，四部门任选 → /join/</span></span>
  <span class="ln" data-type><span class="p">➜ ~</span> <span class="term-cursor"></span></span>
</div>
```

```js
(() => {
  const box = document.querySelector('[data-term]');
  if (!box) return;
  const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
  const lines = Array.from(box.querySelectorAll('[data-type]'));
  if (reduce) { lines.forEach((l) => (l.style.visibility = 'visible')); return; }

  lines.forEach((l) => (l.style.visibility = 'hidden'));
  const typed = box.querySelector('[data-text]');
  const full = typed ? typed.dataset.text : '';

  const showNext = (i) => {
    if (i >= lines.length) return;
    const line = lines[i];
    line.style.visibility = 'visible';
    const t = line.querySelector('[data-text]');
    if (t) {
      const text = t.dataset.text || '';
      t.textContent = '';
      let k = 0;
      const tick = setInterval(() => {
        t.textContent = text.slice(0, ++k);
        if (k >= text.length) { clearInterval(tick); setTimeout(() => showNext(i + 1), 260); }
      }, 55);
      return;
    }
    setTimeout(() => showNext(i + 1), 380);
  };
  showNext(0);
})();
```

**要点**

- `data-text` 存完整文本、`textContent` 逐字刷——不用逐字 `<span>`，DOM 不膨胀。
- 第一帧就把所有行设为 `hidden` 再开始，避免闪一下全文。
- `prefers-reduced-motion` 直接全显，不做减法动画。
- 光标用 CSS `@keyframes` 闪，不占 JS。

## 配方 C：滚动揭示（`data-reveal`）

```js
(() => {
  const els = document.querySelectorAll('[data-reveal]');
  if (!els.length) return;
  if (!('IntersectionObserver' in window) || matchMedia('(prefers-reduced-motion: reduce)').matches) {
    els.forEach((el) => el.classList.add('is-in'));
    return;
  }
  const io = new IntersectionObserver((entries) => {
    for (const e of entries) if (e.isIntersecting) { e.target.classList.add('is-in'); io.unobserve(e.target); }
  }, { rootMargin: '0px 0px -10% 0px', threshold: 0.08 });
  els.forEach((el) => io.observe(el));
})();
```

```css
[data-reveal] { opacity: 0; transform: translateY(10px); transition: opacity .5s ease, transform .5s ease; }
[data-reveal].is-in { opacity: 1; transform: none; }
@media (prefers-reduced-motion: reduce) { [data-reveal] { opacity: 1; transform: none; transition: none; } }
```

**要点**：`unobserve` 一次就停，别在滚动里反复改 className。

## 配方 D：加入我们表单（不进 URL）

```html
<form id="join-form" novalidate>
  <label>姓名 / 昵称 <input name="name" required maxlength="40" autocomplete="name"></label>
  <label>联系方式（微信 / 手机 / 邮箱，任选一种）<input name="contact" required maxlength="80"></label>
  <label>感兴趣的方向
    <select name="track">
      <option>暂不明确</option><option>AI 与大模型</option><option>算法竞赛</option>
      <option>技术开发</option><option>设计与视觉</option><option>活动运营</option><option>都想试试</option>
    </select>
  </label>
  <label>一句话介绍自己（可选）<textarea name="intro" maxlength="200"></textarea></label>
  <button type="submit" id="join-submit" disabled>需要 JavaScript 才能提交</button>
  <p class="form-note" id="join-note">为避免联系方式进入地址栏，本表单在未启用 JavaScript 时不可提交。</p>
</form>

<script is:inline>
(() => {
  const form = document.getElementById('join-form');
  const btn = document.getElementById('join-submit');
  const note = document.getElementById('join-note');
  if (!form || !btn) return;
  btn.disabled = false;
  btn.textContent = '提交报名';
  note.textContent = '提交后由技术组处理；报名信息不会展示在公开页面。';

  form.addEventListener('submit', async (e) => {
    e.preventDefault();
    const data = Object.fromEntries(new FormData(form));
    btn.disabled = true; btn.textContent = '提交中…';
    try {
      const res = await fetch('[FORM_ENDPOINT]', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ ...data, source: 'ca-site', ts: Date.now() }),
      });
      if (!res.ok) throw new Error(String(res.status));
      form.innerHTML = '<p class="ok">收到，技术组会尽快联系你。</p>';
    } catch {
      btn.disabled = false; btn.textContent = '提交报名';
      note.textContent = '提交失败，请稍后重试，或直接联系公众号后台。';
    }
  });
})();
</script>
```

**要点**

- **按钮默认 `disabled`**，脚本跑起来才解禁。这样无 JS 环境下用户看到的就是「需要 JavaScript」而不是提交后丢数据。
- `novalidate` + 自己控校验，避免浏览器默认弹窗打断中文提示。
- 用 `fetch` + JSON，**不用** `<form action>`——后者会把字段塞进 URL。
- 成功后直接替换表单内容，不给用户「再点一次」的机会。
- `[FORM_ENDPOINT]` 待填，见 `docs/03-开源选型.md`。
