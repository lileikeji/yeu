# 四个社团官网的逆向笔记

抓取日期 2026-11-16。四个站都能直接访问，原始 HTML 存档在 `_recon/`（jxauac 五个页面 + CSS、net9、compsoc、mujacm-jina.md）。

| 站 | 归属 | 栈 | 形态 |
|---|---|---|---|
| compsoc.org.nz | 坎特伯雷大学计算机协会（新西兰，since 2004） | WordPress + Salient 主题 + WPBakery | 多页 CMS |
| muj.acm.org | Manipal University Jaipur ACM 学生分会（印度） | 手写单页 HTML，无框架 | 单页锚点 |
| **jxauac.cn** | **江西农业大学计算机协会（est. 2001）** | **Astro v7.2.9** | **多页静态，8 栏目 + 档案 + 搜索** |
| net9.org | 清华大学计算机系学生科协 SAST | Hexo 6.3.0 + NexT 主题 | 多页静态 + 特效层 |

## 1. compsoc.org.nz —— 新西兰人把社团当公司在运营

**技术指纹**

- `meta generator`：WordPress，页面里另有两个 generator 标记（WPBakery Page Builder 6.7.1）
- 主题 Salient 14.0.5，插件 salient-core、salient-portfolio
- 首页首屏就拉 15 个 JS 文件：jQuery 3.7.1 + jquery-migrate 3.4.1、fancybox、superfish、waypoints、anime、hoverintent、touchswipe、imagesLoaded、transit……
- `Server: nginx/1.24.0 (Ubuntu)`，无 CDN，裸机直出
- 首页 HTML 71 KB（gzip 前）

**栏目**：首页 / Sponsor us（→ `/prospectus`）/ Contact Us（`/get-in-touch/`）。页脚只挂 Privacy Policy 与 Constitution（章程 PDF）。

**首页叙事顺序**：hero `kia_ora()`（毛利语问候被写成函数调用，这个梗很妙）→ "Become a member" → 我们为什么特别（events 叙事）→ View upcoming events → 赞助商致谢墙 + "Become our sponsor" → Get in touch → 社交四连（FB/LinkedIn/IG/email）。

**最值得学的一件事**：`/prospectus` —— 把「招新手册 + 赞助招商书」做成一个独立页面。对外拉赞助时有东西可发，不用每次现写 PPT。这是唯一一个把「钱」当一等公民设计进信息架构的站。

**为什么不该照抄**：WordPress + 页面构建器 + 15 个 jQuery 插件的组合，在共享低配机器上意味着 PHP-FPM + MySQL 常驻、插件链要一直跟着升级、任何一次自动更新都可能白屏。学生团队接不住，且和「本机出制品、服务器只解包」的部署纪律冲突。

## 2. muj.acm.org —— 一个 HTML 文件撑起来的招新门面

**技术指纹**：无框架、无构建。`Server: openresty/1.31.1.1` + Cloudflare（`cf-edge-cache`、`CF-RAY`）。安全头齐全：`X-Content-Type-Options` / `Referrer-Policy` / `X-Frame-Options` / `Content-Security-Policy`。首页 12 KB。

直连会被 Cloudflare 拦成 `One moment, please...`，得走阅读代理才拿到正文——说明防护是真的开着。

**导航 8 项全部是锚点**：Home / About Us / Team / Events / Gallery / Projects / Blogs / Contact Us → `#home` `#about` …

**结构（单页纵向）**

1. Hero：`WE ARE MUJ ACM STUDENT CHAPTER` + 一句定位
2. What We Do：3 张卡 —— Workshops & Seminars / Coding Competitions / Projects & Research
3. About Us：先讲 ACM 全球背景（世界最大计算机教育科研组织），再讲 Our Mission
4. 统计三格：`120+ Members` `25+ Events` `10+ Projects`
5. Team：6 个职位卡 + 真人头像 —— Chairperson / Vice-chairperson / Technical Secretary / Treasurer / Secretary / Creative Director
6. Events：**7 个筛选标签**（All / Workshop / Hackathon / Talk / Networking / Competition），24 场活动，每卡 = 分类标签 + 标题 + 📅日期 + 一句描述
7. Gallery：16 张实拍，纯网格
8. Projects：**分类筛选**（All / Web Dev / Mobile / AI·ML / IoT），每卡 = emoji 图标 + 标题 + 描述 + 技术栈标签（如 `Web Dev` `React` `Node.js`）+ GitHub / Live Demo 双链接
9. Blogs → Contact

**值得学**：活动卡与项目卡都带「分类 + 筛选标签」；项目卡强制挂技术栈和三方链接——这让项目墙变成真作品集，而不是自嗨列表。

**不该照抄**：全锚点单页。活动一多就变成一条无限长的滚动条，没有独立 URL，分享不了单场活动，SEO 只有一页。他们能这么干是因为内容量被压在 24 场/10 个项目，且不打算长期沉淀。

## 3. jxauac.cn —— 最贴近我们的那个，几乎可以直接照结构施工

**技术指纹**

- `meta generator: Astro v7.2.9`
- 全部样式一个文件：`/_astro/Base.tvpKmlOP.css`（21.3 KB，未压缩）
- `Server: Angie`（nginx 系），HSTS / X-Content-Type-Options / X-Frame-Options / Referrer-Policy / Permissions-Policy 全开
- 无框架、无前端运行时。页面自述 `built with Astro · zero runtime · 小而美`
- 文章 URL 形如 `/news/20261011-gitea-launch/`（日期 + slug，可读、可排序、不发胖）

**信息架构**

```
/           首页
/news/      动态（标签即专题 + 按月归档）
/activities/ 活动
/projects/  项目
/resources/ 资源
/members/   成员（2026—2027 学年名录，支持按班级筛选）
/about/     关于（含「易变信息核对清单」）
/join/      加入我们（表单 + 隐私说明 + FAQ）
/archive/   档案（2001—2024 历史沿革）
```

导航 = 7 个栏目 + 右侧独立 CTA「加入我们」。页脚三行：`计算机协会` / `est. 2001 · 静态优先 · jxauac.cn` / `搜索 · 档案` / `内容由技术部与 AI 共同维护 · © 2026` / `built with Astro · zero runtime · 小而美`。

**设计 token（从 CSS `:root` 抠出来的，可整段复用）**

```
--bg:#f4f6f1  --surface:#fff  --ink:#14201b  --muted:#5a665f
--accent:#0a7292  --accent-deep:#075c77  --accent-soft:#e2f3f9  --accent-glow:#0a729214
--border:#e2e5de  --border-strong:#cfd4cc
--term-bg:#0e1e26  --term-ink:#c9e7f2  --term-dim:#6a95a3
--warn-bg:#fdf4f1 --warn-border:#d9b3a8   --info-bg:#eef7fc --info-border:#bfd9e8
--radius:14px  --radius-sm:10px  --max:960px
sans: system-ui, -apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"
mono: ui-monospace, "SF Mono", "Cascadia Code", "JetBrains Mono", Consolas
shadow-sm: 0 1px 2px #10221c0d    shadow-md: 0 10px 28px -12px #0a3c4a38
```

body 背景是两层叠加：右上角 58rem×26rem 的径向光晕（`--accent-glow`）+ 26px 间距的点阵网格，`background-attachment: fixed`。这套底色是「小而美」观感的 70%。

**首页首屏**

- 左侧：kicker `JXAU · Computer Association` → h1 `计算机协会` + 打字机光标 → 副文案「小而美 · 一起做有趣的事。我们用 AI 写代码、练算法与编程，也做网站和设计——零基础也能找到自己的位置。」→ 两个按钮（`报名加入` / `看看近期活动`）→ 四格统计 `2001 年成立` `25+ 年传承` `7+ 技术培训` `0 公开页运行时`
- 右侧：仿终端卡，标题栏三圆点 + `zsh — jxauac.cn`，内部逐行打字：
  - `➜ ~ whoami` → `计算机协会 · est. 2001`
  - `➜ ~ cat mission.txt` → `小而美，一起做有趣的事。`
  - `➜ ~ ./join --you` → `[ok] 零基础欢迎，四部门任选 → /join/`
- 往下：`01 最新动态`（卡片 3 条，`全部 →`）、`02 …` 依次排

注意 `0 公开页运行时` 这一格：把技术选择本身当卖点摆到首屏统计里。这是个便宜的差异化动作。

**关于页的杀手锏：一张「易变信息 · 核对清单」表**

| 核对项 | 权威来源 |
|---|---|
| 部门设置与职责 | 2026—2027 学年分工方案 v2.0（四部：办公室 / 活动部 / 技术部 / 竞赛部） |
| 招新时间与报名方式 | 招新页（报名长期开放） |
| 负责人/成员名单 | 成员页；负责人以当届通知为准，往届单独标学年 |
| 公众号名称与联系方式 | 以当届公布为准 |

社团站最大的死法是**信息过期**：三年后没人记得上一届部长叫什么，但页面还挂着。他们把这个矛盾显式化——正文不写死易变信息，只写「去哪里查权威来源」。这一招比任何 CMS 都有效，因为它的维护成本是零。

**加入页把隐私放在功能前面**

- 表单不用原生 `action`，必须 JS 才可提交，理由写在页面上：*「为避免联系方式进入地址栏，本表单在未启用 JavaScript 时不可提交」*
- 数据说明：姓名/联系方式/方向/自述用于处理报名；报名信息不进公开页面；技术组用内部工具处理；**通知消息不含联系方式**；系统记录提交时间与 IP 摘要，摘要属伪名化记录并非完全匿名
- 反向提醒：只填一种联系方式，别填身份证住址
- 诚实声明：*「本站尚未公布统一回复时限、保存期限和独立删除申请渠道；如对此有顾虑，可暂不提交」* —— 承认自己还没做到的部分，比编一句「我们严格保护您的隐私」可信一百倍
- 5 条 FAQ：零基础能来吗 / 加入后做什么 / 怎么报名 / 招新有截止时间吗 / 活动频率高不高

**其他可拆件**：自建 Gitea（`git.jxauac.cn`）承载项目墙的 11 个成员作品；关于页的「协会宗旨」直接抄自注册章程的措辞；标签点进去是专题聚合页；档案页单列。

### 3.1 四个内页的实际形态（照抄级细节）

**`/projects/` 作品集**（7.5 KB，9 个项目）副标：「成员做的项目，从构想到上线都在这里。每个项目都可复现、可继续。」

每项的信息顺序固定：`// 进行中` 状态标记 → `进行中 · Kotlin / Jetpack Compose / 无障碍服务` 技术栈行 → 项目名 → 一句描述。真实项目长这样：

- Andloading — Android 端侧 AI 助手：悬浮窗常驻，无障碍读屏与手势执行，加 Shizuku 高权限工具，让大模型 Agent 直接看懂并操作手机
- 江农工具箱 — 课表/成绩/考试安排/教学计划一屏查，教务掉线自动重连，考试安排一键导出日历
- Selinga — 拖一个透明方框框住屏幕任意区域，框内文字自动 OCR 并即时翻译，免截图免切窗口（Rust / egui+winit / 系统离线 OCR）
- CardGame1 骰子卡牌对战 — **仓颉语言** + CjForm + UDP 局域网自动发现
- Dwalia — Windows 平铺窗口管理器：8 种布局、5 个虚拟工作区、纯键盘驱动、YAML 热重载
- 友利奈绪 QQ 机器人 — Python + NapCat + DeepSeek 主模型，豆包备用，本地 CLIP 识图打标

**这才是项目墙该有的样子**：读者能一眼判断「这些人真的会写东西」。全是可复现的具体技术名词，没有一句「致力于打造」。

**`/resources/` 资源库**（3.8 KB，4 条）副标：「社员沉淀的学习材料；每条可进入详情看完整正文，外链会明确标注去向。」

每条：分类标签（书单 / 入门 / 分享材料 / 工具）+ 日期 + **`含外链 ↗ book.douban.com`（把第三方域名直接印在列表上）** + 标题 + 一句描述。

其中最狠的一条是「工具与镜像站速查 —— **本服务器实测可用的**镜像与工具（npmmirror / 阿里 pypi / git 加速）」。这是只有自己踩过校园网/国内源坑的人才写得出的内容，也是最容易被新生反复访问的页面。

**`/members/` 成员页**（35 KB，87 人）

- 三格数据：`MEMBERS 87 位新成员` / `SCHOOL YEAR 2026—2027` / `CLASS GROUPS 50 个班级`
- `COHORT / 年级分布`：2026级 78 人 / 2025级 8 人 / 2024级 1 人
- `DIRECTORY / 01 成员名录`：`显示 87 位成员` + 姓名搜索框 + 专业下拉（26 个专业）+ 年级下拉 + 「清除筛选」
- 每条：姓氏首字方块 + 姓名 + 专业班级（如 `计科2602`）+ `+` 展开
- 87 条数据 + 三个筛选器，纯前端 JS，无后端

这个页面在低配服务器上是可以接受的（35 KB 静态 HTML），但它同时暴露一个设计选择：**把真实的、可核对的成员名单公开出来**。仰恩要不要公开成员名单是个需要拍板的问题（涉及个人信息），但「按专业/年级分布统计」这部分没有隐私风险，值得做。

**`/activities/` 活动页**（3.3 KB）副标：「按时间倒序排期（近期暂无排期，以下为已结束活动）；报名入口在「加入我们」或活动详情页」，右上「历史活动归档 →」。

每项信息四元组：`2026年9月15日 09:00-21:00 · 共两天 · 创客空间 2F · 已结束` → 标题 → 一句描述。注意它连**时段、时长、地点、状态**都写死了，而且坦白承认「近期暂无排期」。

三场实际活动：48 小时迷你黑客松（面向零基础也友好的组队黑客松）、招新宣讲会（「用一个半小时讲清『加入我们能得到什么』」）、迎新破冰会（「报名截止 8 月 30 日」）。

**它敢写「近期暂无排期」这件事本身**，比挂一堆假活动更可信。

## 4. net9.org —— 清华科协，把首页做成年度报告

**技术指纹**：`meta generator: Hexo 6.3.0` + NexT 主题（页面尾巴那句 `Theme NexT works best with JavaScript enabled` 是主题指纹）。在此之上叠了四个自制层：

- `atmosphere.css` / `atmosphere.js` —— 氛围层
- `mascot-visitor.css` / `mascot-visitor.js` —— 一个会跟着鼠标的吉祥物访客
- `palette-eggs.css` —— 隐藏配色彩蛋
- `motion.js` / `next-boot.js` / `config.js` / `utils.js`

外部依赖走 jsDelivr（Bootstrap 5.3.0）+ cdnjs（Font Awesome 7.0.0、animate.css 3.1.1）+ Cloudflare Insights，前面套 Cloudflare。

**导航**：首页 / 活动 / 服务 / 更多（智能体、暑期培训、基础技能培训、技能引导文档、资源平台）。

**首页 = 给三个部门各写一份带数据的年度简报**

- 「科协记忆」时间线：2026 科协迎新会、2024·科协迎新会、2023·科协迎新会、2022·基础技能培训、2022·科协迎新会、AntWar 智能体大赛、学生节活动掠影
- 然后 `THU-CST SAST / DEPARTMENTS`，一句话总纲：「连接热爱技术的人，把想法变成作品。」
- `01 / CONNECT 科创联络部` —— 定位段 → 「2026 暑期工作与近期成果」亮点卡（Sweetie Agent 血糖洞察助手，含 知识检索/记录分析/开源协作 三标签 + 「阅读完整报道 ↗」「开源代码 ↗」双链）→ 「我们日常在做什么」4 条编号（内联与活动组织 / 外联与行业交流 / 挑战杯支持 / 资源与信息连接）
- `02 / CREATE 智能体部` —— 自 1997 年智能体大赛的传承叙事 → AAArena 亮点卡 + 数据三格（12 款游戏 / 1,920 份人类程序存档 / 7 组评测配置）→ 4 条日常
- `03 / BUILD 网络部 / Infra` —— 暑培 7.0 亮点卡 + 数据三格（11 期常规课程 / 3 期科研分享 / 24 万+ 累计播放，标注「播放量截至 2026 年 9 月 7 日，来源：暑培公开总结」）→ 4 条日常（技能文档与培训 / Project9 实践 / 服务与活动保障 / 技术分享）

**值得学**：每个数字都带截止日期和出处；每个成果卡都挂外部链接而不是自吹。这种「有据可查」的写法在社团站里罕见，它让内容经得起质疑。以及 `01/CONNECT → 02/CREATE → 03/BUILD` 这套部门动词命名，比「部门介绍一/二/三」有精神气。

**不该照抄**：氛围层 + 吉祥物 + 彩蛋加起来是四套自制 JS，只有清华科协这种人力密度撑得住。我们要做的话留一个「氛围层」的口子就够了。

## 5. 横向对比

| 维度 | compsoc | muj.acm | jxauac | net9 |
|---|---|---|---|---|
| 建站成本 | 低（装 WP） | 极低（一个 HTML） | 中（Astro 项目） | 中（Hexo + 主题 + 自制层） |
| 每年维护成本 | **高**（插件升级） | 中（手改 HTML） | **低**（加 md） | 中高（特效层要人） |
| 服务器负担 | PHP + MySQL 常驻 | 静态文件 | 静态文件 | 静态文件 |
| 内容沉淀能力 | 强 | **弱**（无独立 URL） | 强 | 强 |
| SEO / 分享 | 一般 | **差** | 好 | 好 |
| 首屏辨识度 | 高（商业主题） | 中 | **高**（终端 + 点阵） | 高（吉祥物） |
| 学生可接手度 | 低 | 高 | **高** | 低 |
| 迁移/重建 | 难 | 易 | **易**（md 全在仓库） | 易 |

结论很干脆：**结构抄 jxauac，视觉换成仰恩的，活动/项目的分类筛选借 muj，赞助与章程页借 compsoc，特效层留口子学 net9 但不实现。**

## 6. 可以直接搬的 13 个零件

1. **终端演示当 hero 右半** —— 零图片、零依赖、辨识度极高，纯 CSS + 20 行 JS。
2. **序号 section**（`01 最新动态` / `02 我们做什么`）—— 免费拿到视觉节奏感。
3. **「易变信息 · 核对清单」表** —— 治信息腐化，维护成本为零。
4. **页脚四段信息**，末尾挂 `built with Astro · zero runtime · 小而美` —— 一句话把技术选择变成社团性格。
5. **表单不进 URL + 无 JS 明确禁用** —— 保护报名者联系方式，且理由写在界面上。
6. **隐私说明分「用途 / 不外显 / 只收一种联系方式 / IP 摘要属伪名化」四段**，并诚实标注还没做到的（删除渠道）。
7. **表单后接 FAQ 5 条** —— 拦住 80% 的重复咨询。
8. **档案页单列**（历史沿革占位时间线）—— 让「我们 20 年了」这句话有落点。
9. **标签即专题** —— 一篇文章多标签，点标签看聚合。
10. **活动卡分类筛选**（muj 的 7 类标签）—— 内容过 20 条之后必备。
11. **项目卡强制三件套**：技术栈标签 + GitHub 链接 + 在线 Demo —— 项目墙立刻从自嗨变作品集。
12. **统计数字只用可核验的**，且带截止日期与来源（net9 的做法）。
13. **部门用动词命名**（CONNECT / CREATE / BUILD 这种），比「部门一二三」有精神。
14. **独立招募/赞助手册页**（compsoc `/prospectus`）—— 拉赞助时的现成物料。
15. **自建 Gitea 承载项目墙**（jxauac `git.jxauac.cn`）—— 顺便把社团代码资产集中。

## 7. 对仰恩的推论

1. **技术选型只有 Astro 一个答案**。理由不是审美，是部署纪律：`~/.agents/AGENTS.md` 明文规定生产机 `124.221.145.182`（4 核 / 3.6G / 同机 50+ 站点 / 根盘 40G 已用 82%）禁止构建，必须「本机出制品、服务器只解包切换」。结论：静态产物 + 本机 16 核构建，正好落在既有链路里；WordPress 那条路直接违反纪律。
2. **可以直接复用 yeu 项目的发布管道**：本机 `build-linux-artifact.sh` 式打包 → 服务器 `deploy-incoming.sh` 校验/备份/冒烟/切换（35–90 秒）；部署串行用 flock 锁；低配机构建有 8 核 8G 硬守卫（`ALLOW_LOW_SPEC_BUILD=1` 才放行）。社团站不需要另造一套。
3. **配色换掉**。jxauac 的青蓝（`#0a7292`）是他们的气质，我们用仰恩的红，其余 token 结构照搬（见 `docs/02-建站方案.md`）。
4. **栏目从 8 个起步就够**：首页 / 动态 / 活动 / 项目 / 资源 / 成员 / 关于 / 加入我们（+ 档案）。再多就是给未来的自己挖坑。
5. **不写死的三件事**：成立年份、获奖数量、成员人数。这三样最容易变成假话。用占位符等着填真实值。
